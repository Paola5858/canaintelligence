# Skills locais do Cana Intelligence

Regras práticas para montar os visuais deste relatório no Power BI. São locais do projeto: não foram instaladas em nenhum diretório global, não são pacotes e não valem para outros projetos sem revisão.

| Skill | Quando usar |
| --- | --- |
| [skill-card-kpi](skill-card-kpi/SKILL.md) | Cartões de valor único e faixas de indicador |
| [skill-line-chart](skill-line-chart/SKILL.md) | Séries temporais, com ou sem lacuna |
| [skill-bar-chart](skill-bar-chart/SKILL.md) | Ranking, comparação de grupo e faixa observada |
| [skill-matrix-table](skill-matrix-table/SKILL.md) | Matriz de comparação e tabela de detalhe |
| [skill-data-quality-table](skill-data-quality-table/SKILL.md) | Tabela de pendências e auditoria |
| [skill-page-layout](skill-page-layout/SKILL.md) | Grade, hierarquia e rodapé de página |
| [skill-tooltip-and-interactions](skill-tooltip-and-interactions/SKILL.md) | Tooltip, filtro cruzado, drill-through |

Cada skill tem uma lista de verificação no final. Se um item falhar, o visual não está pronto, mesmo que pareça bonito.
